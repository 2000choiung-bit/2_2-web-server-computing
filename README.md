# 🌐 웹서버 컴퓨팅

부천대학교 컴퓨터소프트웨어과 **웹서버 컴퓨팅** 수업 내용 및 주차별 과제 정리 저장소입니다.

## 📁 주차별 학습 및 과제 목차

| 주차 | 주요 학습 내용 | 과제 / 실습 내용 | 상태 |
| :--- | :--- | :--- | :---: |
| **01주차** | JSP 개요 | 웹과 JSP 프로그래밍 이해, JSP 개발 환경 구축, `<웹 쇼핑몰>` 프로젝트 생성 | 완료 |
| **02주차** | 스크립트 태그 | 선언문, 스크립틀릿, 표현식 태그의 기능과 사용법, `<웹 쇼핑몰>` 시작 페이지 제작 | 완료 |
| **03주차** | 디렉티브 태그 | page, include, taglib 디렉티브 태그 기능과 사용법, 한글 출력 및 페이지 모듈화 | 진행 중 |
| **04주차** | 액션 태그 및 내장 객체 | forward, include, param, 자바빈즈 액션 태그, request/response/out 내장 객체 활용 상품 목록 및 상세 정보 표시 | 대기 |
| **05주차** | 폼 태그 | form, input, select, textarea 태그 기능 및 폼 데이터 처리, `<웹 쇼핑몰>` 상품 등록 페이지 제작 | 대기 |
| **06주차** | 파일 업로드 | MultipartRequest 및 Commons-FileUpload를 이용한 파일 업로드, 상품 이미지 등록 | 대기 |
| **07주차** | 유효성 검사 | 기본 유효성 검사 및 데이터 형식 유효성 검사, 상품 등록 데이터 검사 | 대기 |
| **08주차** | **중간평가** | 1~7주차 학습 내용 정리 및 평가 | 대기 |
| **09주차** | 예외 처리 | page 디렉티브 및 web.xml 파일을 이용한 예외 처리, `<웹 쇼핑몰>` 예외 처리 페이지 제작 | 대기 |
| **10주차** | 필터 | Filter 인터페이스 구현 클래스, web.xml 필터 구성, 로그 기록 기능 구현 | 대기 |
| **11주차** | 세션과 쿠키 | 세션/쿠키 생성, 정보 조회, 삭제 처리, 장바구니 및 주문 처리 페이지 제작 | 대기 |
| **12주차** | 데이터베이스 개발 환경 구축 | MySQL 개발 환경 구축, 통합 개발 환경과 DB 연동, 상품 관리 테이블 생성 및 상품 등록 | 대기 |
| **13주차** | JDBC로 데이터베이스와 JSP 연동 | JDBC 드라이버 로딩, DBMS 접속, 쿼리 실행 및 결과 조회, 상품 조회/등록/수정/삭제 구현 | 대기 |
| **14주차** | 프로젝트 수행 | 스토리보드 작성, 프로젝트 시뮬레이션 및 리허설, 회원 가입/수정/탈퇴 기능 구현 | 대기 |
| **15주차** | **기말평가** | 1~14주차 학습 내용 정리 및 종합 평가 | 대기 |

## 🛠 사용 환경
* **Language / Spec:** Java, JSP, Servlet, HTML/CSS
* **Server / DB:** Apache Tomcat, MySQL
* **Tools / Library:** Eclipse / IntelliJ, JDBC, Commons-FileUpload
